# Alam Sari Cup — extracted visual assets

PNG crops extracted from the supplied futuristic mobile mockup.

## Assets
- `brand-logo-mark.png`: volleyball mark only (cropped from mockup).
- `brand-lockup.png`: logo mark plus tournament wordmark.
- `hero-volleyball.png`: hero volleyball artwork crop.
- `team-*.png`: team crest crops.
- `design-reference.png`: full mockup reference; do not use as the page background.

## Suggested usage
Put these files in `public/assets/` in a Next.js project. Reference them with paths such as `/assets/brand-logo-mark.png`. The crops retain parts of the original dark background and are raster images, not transparent/vector logos. For production, consider recreating the wordmark and team crests as SVGs, or use these crops on a matching dark navy background.

The mockup includes illustrative sample teams and scores. Replace them with official tournament data before publishing.
